How to use

  • Add note: choose a pitch and click “Add note”, or press a piano key on the computer keyboard (A W S E D F T G Y H U J K = C3 … C4). Notes land at a random free spot. The first note becomes the start note. Every further note is connected to the active (selected) note by two vectors, one each way, and then becomes the active note.
  • MIDI keyboard: pick your controller under “MIDI in” (bottom bar) and a channel (Omni = all). Each incoming note-on adds that note. Edge asks for MIDI permission on first use.
  • Playback: choose “MIDI out” (e.g. a loopMIDI/Windows MIDI port that Ableton listens to), set a start note and press Start. From the current note the next one is picked among all paths following its outgoing vectors (through routing circles until the next note). Shorter paths are more likely (weight = 1 / path length). Pause keeps the position, Stop resets it. A note without any outgoing path ends the sequence.
  • Probability: select a note and set “Probability %” in the toolbar. The circle's diameter shows it: 100 % = full size (default), 0 % = half size. When the walk reaches a note, it sounds with that probability; otherwise that step is a rest and the walk continues.
  • Move: drag a circle.
  • Draw a vector: drag from the outer ring of a circle onto another circle.
  • Routing circle: click “Routing circle” or double-click an empty spot.
  • Select / delete: click a circle or vector, then press Delete.
  • Start note: select a note and click “Set as start” (click again to unset). Only one note can be the start; it is shown in gold with a star.

Prototype: velocity and note length are global settings in the toolbar; detailed timing model still to be defined.
